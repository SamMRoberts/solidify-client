# Resources

This directory holds curated evidence and provenance for the planned client. It contains Markdown only; no captured traffic, images, audio, binary fixtures, or runtime profiles are bundled.

- [Primary references](references/README.md): verified technical sources and their scope.
- [Fixture conventions](fixtures/README.md): provenance, redaction, byte notation, and expected outcomes for future tests.
- [Asset conventions](assets/README.md): licensing, attribution, and future source/export organization.

Maintained architecture and developer guidance belong in [docs](../docs/README.md). Runtime profiles, maps, credentials, and generated test/build output belong outside this resource collection.
