# Asset provenance

## Scope

Own planned visual and audio asset organization and attribution. These instructions supplement ancestor `AGENTS.md` files for this subtree. The directory currently contains documentation only.

## Working guidance

- Record source, author, license, permitted uses, modifications, and attribution before adding an asset.
- Separate editable source from distributable outputs when assets arrive and keep generated build output elsewhere.
- Use accessible and appropriately sized assets; do not add binaries during the Markdown scaffold task.

## Verification

Verify reuse rights and references; do not imply an empty asset collection provides application icons or bundled audio.
