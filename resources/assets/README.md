# Asset conventions

## Current contents

No images, icons, fonts, audio, or other binary assets are included. No asset license or project-wide license is implied by this scaffold.

## Metadata required before adding assets

Record the asset name and intended use, original source URL or creation provenance, author/rightsholder, license and applicable version, permitted redistribution/modification, required attribution, and any modifications.

For generated material, record the generation source and any relevant input rights or usage terms. Do not treat availability online as permission to redistribute. Do not include credentials or private generation inputs.

## Future organization

When assets are introduced, separate editable originals and distributable exports by purpose, such as application icons, interface illustrations, or audio. Add directories only when they contain actual resources and provenance. Keep build-generated bundles outside this source collection.

Record dimensions, format, export settings, and accessibility considerations where relevant. Fonts need redistribution rights; sound resources need provenance and playback policy. Server-requested media must not become a trusted bundled asset without review.
