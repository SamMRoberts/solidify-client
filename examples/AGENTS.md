# Contributor examples

## Scope

Own examples that teach supported extension behavior. These instructions supplement ancestor `AGENTS.md` files for this subtree. The directory currently contains documentation only.

## Working guidance

- Keep examples small, documented, and consistent with the actual host API when it exists.
- Do not describe planned examples as runnable or add fake interfaces to make them appear complete.
- Record compatibility and required capabilities alongside examples; use synthetic non-sensitive data.

## Verification

Check example instructions against the implementation and build or run examples only after their manifests exist.
