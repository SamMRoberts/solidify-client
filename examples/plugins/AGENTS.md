# Plugin examples

## Scope

Own author-facing examples separated by proposed runtime. These instructions supplement ancestor `AGENTS.md` files for this subtree. The directory currently contains documentation only.

## Working guidance

- Read the plugin design before adding examples; no runtime has a published host contract yet.
- Use minimal permissions, explicit event cleanup, and plugin-scoped storage.
- Explain installation, removal, compatibility, and failures once supported; avoid examples that depend on private servers.

## Verification

Validate each implemented example against the supported host version, including reload or unload behavior if offered.
