# Operations documentation

## Scope

Own proposed automation, security review, packaging, and release procedures. These instructions supplement ancestor `AGENTS.md` files for this subtree. The directory currently contains documentation only.

## Working guidance

- Separate ordinary checks from privileged release and deployment actions.
- Record prerequisites, inputs, outputs, failure handling, and meaningful evidence for each procedure.
- Do not invent configured schedules, signing identities, supported versions, release history, or private reporting contacts.

## Verification

Confirm role coverage, permissions, release gates, and security assumptions against actual configuration when introduced.
